# web-tic-tac-toe-with-score-tracking-36415-36433

This workspace contains a retro-themed Tic Tac Toe game implemented with React.

## Project Structure
- `tic_tac_toe_frontend/` — React app (Create React App)

## Run the frontend
```bash
cd tic_tac_toe_frontend
npm install
npm start
```

Then open http://localhost:3000 in your browser.

## Features
- Two-player 3x3 Tic Tac Toe
- Win/draw detection and winning-line highlight
- Scoreboard for X, O, and Draws (persists across rounds)
- Controls:
  - New Round (keeps scores)
  - Reset All (clears board and scores)
- Retro theme styling with accent colors (#3b82f6 and #06b6d4)
- Responsive, centered layout
